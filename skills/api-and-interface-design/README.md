# api-and-interface-design

Architecture workflow skill for designing stable APIs, module boundaries, and public interfaces.

## Use when

- Designing REST, GraphQL, or internal module contracts
- Defining component prop interfaces or cross-team boundaries
- Planning backward-compatible API evolution

## Related skills

- `deprecation-and-migration` — removing or replacing public interfaces
- `word-document` — formal HLD/LLD/ADR deliverables

Install: `bash scripts/install_library.sh skills cursor` from the architect-library repo.
