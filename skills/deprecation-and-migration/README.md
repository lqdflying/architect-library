# deprecation-and-migration

Architecture workflow skill for sunsetting systems, APIs, and features safely.

## Use when

- Replacing an old system, API, or library
- Planning strangler-pattern or feature-flag migrations
- Deciding whether to maintain legacy code or invest in removal

## Related skills

- `api-and-interface-design` — designing replacement interfaces
- `word-document` — migration plan or deprecation notice deliverables

Install: `bash scripts/install_library.sh skills cursor` from the architect-library repo.
