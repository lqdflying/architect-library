# tmp/

Staging area for **external reference** skills, agents, or other material before absorption into architect-library.

- Drop ref folders here (e.g. `tmp/skills/<name>/`) for review.
- Maintainer workflow: [`.cursor/skills/absorb-reference-materials/SKILL.md`](../.cursor/skills/absorb-reference-materials/SKILL.md)
- After review: high-value items move to `skills/` or `agents/`; ignored material is removed or left here until you choose to clean `tmp/`.

This file exists so Git tracks the `tmp/` directory when it has no other content.
